# code-change

Use para bugs, implementação e refatoração.

## Procedimento

Inspecione contexto, proponha diff mínimo, execute testes em sandbox quando disponível. Solicite aprovação externa para escrita real, deploy e merge.

## Saída

Entregue um artefato verificável e declare incertezas, riscos e próximos passos. Consulte [documentação](../../docs/skills/code-change.md) quando precisar de exemplos e limites.
