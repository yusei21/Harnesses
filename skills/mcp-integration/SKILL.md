# mcp-integration

Use quando acessar ferramentas/recursos externos via MCP.

## Procedimento

Identifique servidor confiável, capacidades, permissões, timeouts e validação de entradas/saídas. MCP é conexão com ferramentas, não A2A.

## Saída

Entregue um artefato verificável e declare incertezas, riscos e próximos passos. Consulte [documentação](../../docs/skills/mcp-integration.md) quando precisar de exemplos e limites.
